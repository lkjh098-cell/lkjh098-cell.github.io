# ZERO PROBLEMS

한국어로 제공하는 서울 관광 공모전 시연 사이트. 선택한 출발 시각·이용 가능 시간에 확인된 방문 불가 조건을 제외하고, 선호 조건에 맞는 후보를 정렬합니다. 보라색·분홍색 그라데이션, 둥근 카드, 선택형 칩과 육하원칙 탭을 유지합니다.

## 실행 및 배포

빌드 과정 없는 정적 사이트입니다. 저장소 루트의 HTML·JS·CSS·이미지를 GitHub Pages에 배포합니다. `python3 -m http.server 8765`로 로컬 화면을 열 수 있습니다. 실제 API는 Worker에서 허용한 Origin으로 접속해야 합니다. `config.js`는 공개 설정이고 비밀 값을 포함하지 않습니다.

기존 `zp-proxy` Worker와 계정 설정은 그대로 사용합니다. `proxy.worker.js`는 기존 원본이며 이 수정의 배포 대상이 아닙니다. 비짓서울 API 키는 기존 Worker Secret에만 존재합니다.

Google Maps JavaScript API 키가 있으면 Google 지도를 표시합니다. 로딩·인증 실패 시 다른 지도로 바꾸지 않고 한국어 오류와 확인된 오류 코드를 표시합니다. 키가 없을 때만 기존 폴백을 사용합니다. 로컬 미리보기의 키 강제 삭제 설정은 제거했습니다. 실제 배포 주소와 로컬 주소의 리퍼러 허용 여부는 별개입니다.

## 사진과 AI 소개

`catalog.js`에는 기존 비짓서울 API에서 상세 조회가 성공한 서울 장소·행사 56곳의 조사 자료와 공식 사진 URL이 들어 있습니다. 수집한 60건 중 서울 밖 4건은 제외했습니다. 대표 사진 56개 모두 이미지 응답을 확인했습니다. 조사 자료는 현재 방문 가능 추천과 별도로 표시합니다.

AI가 공식 요약·설명·태그를 읽고 56개의 짧은 소개와 112개의 키워드별 설명을 사전 작성했습니다. `explanations.js`는 선택한 활동 키워드에 맞는 설명을 골라 보여줍니다. 관련 근거가 없으면 기본 소개와 관련성 미확인 안내를 표시합니다. 실시간 AI 호출이 아니므로 별도 서버나 AI 비밀 키가 필요하지 않습니다. 새 API 장소에 사전 작성 설명이 없으면 공식 소개로 명확히 구분합니다.

`gallery.js`는 조사 자료의 사진·AI 설명을 표시합니다. 상세 API가 실패할 때 `place.js`는 조사 당시 자료임을 알리고 현재 운영 여부를 미확인으로 표시합니다. 조사 자료를 현재 방문 가능 판정에 사용하지 않습니다.

## 판정과 점수

하드 조건은 점수로 완화하지 않습니다. 확인된 휴무·운영 종료·행사 시작 전이나 종료 후·도착 시 입장 불가·이용 가능 시간 부족·필수 접근 동선 불가·적용이 확인된 방문 규제를 제외합니다. 예약이나 운영정보가 불명확하면 `방문 전 확인 필요`로 분리합니다. 엘리베이터나 장애인 화장실의 존재를 전체 휠체어 동선 보장으로 해석하지 않습니다.

소프트 선호는 활성화한 축만 합계 100점으로 환산합니다. 기본 비중은 접근 정보 30, 비용 25, 웹사이트 언어 20, 선호 이동시간 15, 관심사 10입니다. 필수 접근 조건은 별도의 하드 판정을 먼저 통과해야 합니다. `무료 이용` 목적은 비용 비중을 50으로 높입니다. 충족은 해당 비중을 획득하며, 불충족과 미확인은 획득 점수가 없습니다. 미확인 비중은 별도로 표시하여 불충족과 구별합니다.

기본 추천은 하드 조건 통과 후 70점 이상, `대안 더 보기`는 50점 이상입니다. `완전 충족만`은 모든 활성 선호를 확인한 후보만 보입니다. 선호를 선택하지 않으면 하드 조건을 통과한 후보를 표시합니다. 점수 기준 밖 후보와 실제 방문 불가 후보는 별도 접힌 영역에 둡니다. 알 수 없는 운영조건을 완전 충족으로 세지 않습니다.

비짓서울 `cmmn_hmpg_lang`은 **홈페이지 운영 언어**입니다. 현장 직원·안내판·오디오 가이드 언어로 표시하지 않습니다. 시연 사이트의 UI는 한국어만 제공하며 웹사이트 언어 선호와는 별개입니다. API 근거가 없는 혼잡도 정렬·실내 여부 판정은 제공하지 않습니다. 목적·동행의 자유입력은 추천에 반영되지 않는 메모로 표시하고, 활동 자유입력은 검색어로 사용합니다.

## 데이터와 성능

확인한 API는 `POST /api/v1/contents/list`, `POST /api/v1/contents/info`입니다. 실측 응답의 `result_code: 200`, `data`, `paging.page_no/page_size/total_count`, 중첩된 상세 필드를 검증합니다. 비짓서울 키 헤더는 Worker가 추가합니다. 코드 추정값으로 오류 응답을 성공 처리하지 않습니다.

실제 상세 50곳 확인을 목표로 선택 분야를 먼저 조회합니다. 부족하면 다른 분야로 확장하고 이를 화면에 알립니다. 서울 밖 주소가 명시된 항목은 목표 수에 포함하지 않습니다. 분류별 최대 4페이지, 상세 동시 조회는 3건입니다. 상세가 도착하는 대로 화면을 갱신하며 `후보 더 확인하기`로 조회 범위를 늘릴 수 있습니다. 전체 서울 관광지를 모두 확인한 것처럼 수를 표시하지 않습니다. 중복 콘텐츠는 제거하고 분류별 전체 수에는 분류 간 중복 가능성을 표시합니다. 일부 실패는 누락 수와 재시도를 표시하고, 전체 실패는 조회 오류로 처리합니다.

장소별 상세 캐시는 5분이며 API와 시연 데이터를 분리합니다. 출발지와 판정 결과는 상세 캐시에 넣지 않습니다. 정렬·선호 점수 필터 변경은 API 재조회 없이 다시 계산합니다. 사용자가 명시적으로 선택할 때만 시연 예시를 사용하고, 모든 관련 화면에 시연임을 표시합니다.

## 검증

검증용 배포 패키지에 포함된 tests 폴더에서 Node.js 20 이상으로 별도 설치 없이 실행합니다.

```sh
node tests/engine.cjs
node tests/expanded.cjs
node tests/google-map.cjs
node tests/catalog.cjs
node tests/ui-flow.cjs
node tests/syntax.cjs
```

`tests/fixtures`는 공개 API에서 받은 응답 구조 표본입니다. 검사는 운영시간·휴무·기간·필수 접근 조건·점수 경계, 캐시·중복 페이지·조회 실패, Google 지도 오류·시간초과·인증 거부, 결과 전환, 사진·AI 소개와 조사 자료 분리를 확인합니다. 자동 검사는 실제 모바일 브라우저의 화면·터치 검사를 대체하지 않습니다.

## 판정의 범위

- 여러 시간대, 계절·요일 예외, 모호한 휴무 문구는 추측하지 않고 확인 필요로 둡니다.
- 이동시간은 직선거리 기반 추정입니다. 실제 대중교통 경로, 계단, 환승, 교통 상황을 확인하지 않습니다. 운영 경계에는 최소 5분 또는 추정시간의 25% 여유를 적용해 불확실한 후보를 분리합니다. 이는 측정된 오차 보증이 아닙니다.
- 최소 방문시간 20분을 기본값으로 사용합니다. 모든 장소의 실제 적정 관람시간을 뜻하지 않습니다.
- 북촌의 실제 레드존 경계와 비짓서울 콘텐츠 ID 대응은 미확인입니다. 이름·주소만 일치하는 실제 장소를 레드존 내부라고 단정하지 않고, 제한 시간에는 구역 확인 필요로 분리합니다.
- 2026년 공휴일 표를 사용합니다. 이후 연도 공휴일 관련 판정은 확인 필요입니다. 임시공휴일·현장 긴급 통제 등 변경 정보는 운영기관 공지 확인이 필요합니다.
- 로그인·서버상 사용자 프로필 저장은 없습니다. 선택 조건은 브라우저 세션에 저장되며, 지도·주소 검색·길찾기를 사용하면 해당 지도 제공자로 좌표나 검색어가 전송될 수 있습니다.
